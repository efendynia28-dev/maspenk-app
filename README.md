# MP mini
Standalone HTML/CSS/JS builder for Android.

The app is intentionally independent from the old MASPENK V29 UI. `app/src/main/assets/index.html` is the MP mini editor and is editable at runtime.

## Build on GitHub
Push this folder to a GitHub repository, then open Actions -> Build MP mini APK -> Run workflow. The workflow builds `app-debug.apk` and publishes it as an artifact.
